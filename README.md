# OpenCode-HyperDCP

**OpenCode-HyperDCP** is a context management plugin for the OpenCode AI coding agent framework, forked from **opencode-dynamic-context-pruning plugin**[https://github.com/Opencode-DCP/opencode-dynamic-context-pruning] (version 3.1.12: [https://github.com/yuriha-chan/OpenCode-HyperDCP/tree/0657cd2fd50e9891cd69eae3787bcf280fabc2ba])

The plugin aims to offer 100% control of the context window and achieve 'lossless' experience:

- Review conversation summaries (for humans)
- Command to manually mark an individual message as protected
- Command and AI tool for rewriting block summaries
- Command to toggle between multiple versions of context summaries for a block
- Command to prune a specific context messages block entirely 
- Provide tool for search & retreive of compressed message (for AI)
- Compression range listing page for humans and informative reminders for AIs - prevent "uncompressed messages leak"
